# Aslan Football Mobil Web

Bu sürüm telefondan Safari veya Chrome ile kullanılabilir.

## Aynı Wi‑Fi ağında kullanma

Bilgisayarda:

```bash
./scripts/start.sh
```

Telefon aynı Wi‑Fi ağındayken:

```text
http://BILGISAYAR_IP_ADRESI:8000
```

## iPhone ana ekranına ekleme

1. Safari'de uygulamayı açın.
2. Paylaş düğmesine dokunun.
3. **Ana Ekrana Ekle** seçeneğini seçin.

## Android ana ekranına ekleme

1. Chrome'da uygulamayı açın.
2. Menüden **Uygulamayı yükle** veya **Ana ekrana ekle** seçeneğini seçin.

## Bilgisayara bağlı olmadan kullanma

Paket bir internet sunucusuna kurulmalıdır. Kurulumdan sonra uygulama HTTPS
adresi üzerinden her yerden açılır ve telefonda uygulama gibi ana ekrana
eklenebilir.
