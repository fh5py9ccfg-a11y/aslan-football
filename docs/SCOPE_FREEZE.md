# Scope Freeze

Bu sürümden sonra yeni modül eklenmez.

Sadece şu işler kabul edilir:

- Kritik hata düzeltmeleri
- Güvenlik düzeltmeleri
- Performans iyileştirmeleri
- Pilot kullanıcı geri bildirimleri
- Tahmin kalibrasyonu
- Veri entegrasyonu düzeltmeleri

Yeni özellikler pilot sonrasındaki 2.0 planına taşınır.
