# Build 010 — Model Registry, Rolling Backtest & Drift Detection

## Model registry

- Model sürümü
- Yarışma kapsamı
- Özellik seti
- Eğitim örneklem sayısı
- Doğrulama Brier skoru
- Doğrulama log loss
- CANDIDATE / ACTIVE / ARCHIVED yaşam döngüsü

## Rolling backtest

Son 5–100 değerlendirilmiş tahmin üzerinden:

- Sonuç doğruluğu
- Tam skor doğruluğu
- Ortalama gol hatası
- Ortalama Brier skoru

## Drift detection

- Doğruluk değişimi
- Kalibrasyon bozulması
- Gol hata değişimi
- Olasılık dağılımı kayması

Model drift raporu, yeniden eğitim veya manuel inceleme ihtiyacını işaret eder.
