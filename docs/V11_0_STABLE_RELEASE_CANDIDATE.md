# v11.0 Stable Release Candidate

## Release manifest

Her release; build ID, source revision, schema version, rollback tabanı ve kritik
component digest'lerini içeren SHA-256 doğrulanabilir manifest üretir.

## SBOM

CycloneDX 1.5 uyumlu yazılım bileşen listesi ve document digest üretilir.

## Release certification

Release bütünlüğü, kritik component digest'leri ve operational certification
tek sonuçta birleştirilir.

## Rollback metadata

Minimum güvenli rollback sürümü manifest içinde açıkça tanımlanır.

## Release channel

Yalnızca `rc` ve `stable` channel sertifikasyon için uygundur.
