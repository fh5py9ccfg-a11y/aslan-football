# MVP 0.3 Hızlı Başlangıç

```bash
docker compose up --build
```

Tarayıcı:

```text
http://localhost:8000
```

## Yeni kullanım alanları

- Oyuncu uygunluğu: AVAILABLE, INJURED, SUSPENDED, DOUBTFUL, REST
- Antrenman oturumu oluşturma
- Oyuncu katılımı: PRESENT, ABSENT, LIMITED, EXCUSED
- Planlanan maçlar için kadro seçimi
- Sakat veya cezalı oyuncunun kadroya alınmasını engelleme
