# MVP 0.2 Hızlı Başlangıç

```bash
docker compose up --build
```

Tarayıcı:

```text
http://localhost:8000
```

## Yenilikler

- Demo verisi tek tuşla kurulabilir.
- Oyuncular aranabilir ve pozisyona göre filtrelenebilir.
- Oyuncular düzenlenebilir veya silinebilir.
- Planlanan maçlara arayüzden sonuç girilebilir.
- Kadro CSV olarak dışa aktarılabilir.
