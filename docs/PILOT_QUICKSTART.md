# Pilot Quick Start

1. `.env.example` dosyasını `.env` olarak kopyalayın.
2. Güvenlik sırlarını değiştirin.
3. `docker compose up --build` komutunu çalıştırın.
4. Oyuncu ve fikstür verilerini CSV ile yükleyin.
5. Kulüp ve rakip güç profillerini oluşturun.
6. Aktif modeli kaydedin.
7. Tek komut tahmin pipeline'ını çalıştırın.
8. Release gate sonucunu kontrol edin.
9. Pilot hazırlık raporundaki aksiyonları tamamlayın.

Yerel demo parolaları internet ortamında kullanılmamalıdır.
