# Build 015 — Release Candidate Quality Gate

## Tek komut pipeline

- Maç tahmini
- Veri kalite kontrolü
- Güven uyarıları
- İnsan onayı veya inceleme işareti
- Karar raporu
- Release gate
- Pipeline süre ölçümü

## Release gate

Kontroller:

- Otomatik test durumu
- Minimum oyuncu ve fikstür verisi
- Aktif model
- Backtest
- Kalibrasyon
- Tekrarlanabilirlik
- Pilot dokümantasyonu

Çıktı:

- GO
- CONDITIONAL_GO
- NO_GO

## Pilot hazırlığı

- Kadro
- Fikstür
- Tahmin
- Model izleme
- Dokümantasyon
- Operasyonel hazırlık skoru
