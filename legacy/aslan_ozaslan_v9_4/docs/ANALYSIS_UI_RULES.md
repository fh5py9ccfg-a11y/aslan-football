# Analiz Arayüzü Kuralları

Arayüz şu bilgileri ayrı gösterecektir:
- model olasılığı,
- veri güveni,
- piyasa olasılığı,
- beklenen gol,
- ana faktörler,
- karşı faktörler,
- veri eksikleri,
- model sürümü,
- hesaplama zamanı.

Gerçek sağlayıcı bağlantısı veya doğrulanmış veri yoksa yüzde alanları görünmez.
Sistem bu durumda açıkça “Analiz çalıştırılmadı” mesajı verir.
