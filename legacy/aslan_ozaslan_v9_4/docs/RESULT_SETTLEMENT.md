# Sonuç Yerleştirme

Yalnızca status=OK olan tahminler sonuçlandırılır.

İşlem:
1. Maç sonucu fixture ID ile eşleştirilir.
2. 1-X-2 gerçek sonucu belirlenir.
3. En yüksek model olasılığı tahmin sonucu kabul edilir.
4. İsabet bilgisi, model sürümü ve veri güveniyle kaydedilir.
5. BLOCKED analizler başarı hesabına dahil edilmez.
